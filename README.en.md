# TeachMeSkills

A blue circle that moves around the screen. A TeachMeSkills study project.

## What it does

Up, down, left, and right buttons move the circle by one step. At the edge of the screen the move stops and an error label appears. Another button opens a second full-screen page, with a way back.

## Course

TeachMeSkills, June 2023. An exercise in screens, storyboards, and frames.

## Stack

UIKit, Storyboard.

## Run

```bash
git clone https://github.com/dpogonia/CircleAnimation-TEACHMESKILLS.git
cd CircleAnimation-TEACHMESKILLS
open TMSkills.xcodeproj
```

Run the **TMSkills** scheme on an iPhone simulator. A second project file sits next to this one; this is the project to open.
