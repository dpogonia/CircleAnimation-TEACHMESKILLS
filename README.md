# TeachMeSkills

Синий кружок, который двигается по экрану. Учебный проект школы TeachMeSkills.

## Что умеет приложение

Кнопки вверх, вниз, влево и вправо сдвигают кружок на один шаг. У края экрана движение останавливается и появляется подпись об ошибке. Отдельная кнопка открывает второй экран на весь дисплей, оттуда можно вернуться.

## Курс

Школа TeachMeSkills, июнь 2023. Упражнение на экраны, storyboard и координаты.

## Стек

UIKit, Storyboard.

## Запуск

```bash
git clone https://github.com/dpogonia/TeachMeSkillsApp-TeachMeSkills.git
cd TeachMeSkillsApp-TeachMeSkills
open TMSkills.xcodeproj
```

Запустите схему **TMSkills** на симуляторе iPhone. Рядом лежит второй файл проекта, рабочий этот.
